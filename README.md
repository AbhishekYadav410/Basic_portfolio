## 🚀 Key Features

- **Dual-Theme Engine**: Obsidian dark-mode with glowing cyber-crimson accents by default, with instant toggle to modern light mode.
- **Interactive Typewriter Effect**: Dynamic animated roles highlighting software engineering and AI competencies.
- **Project Showcase & Filtering**: Filterable grid displaying featured repositories with live tags, GitHub repository links, and architectural highlights.
- **Responsive Architecture**: Mobile-first design adapting seamlessly across desktop, tablet, and mobile displays.
- **Performance Optimized**: Zero external runtime dependencies or heavy frameworks for instantaneous loading speeds.
- **Interactive Contact Form**: Client-side validation with real-time feedback and toast notifications.
- **Resume Access**: One-click direct download and preview of Abhishek Yadav's resume.

## 🏃 Running Locally

To preview or run this website locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AbhishekYadav410/Basic_portfolio.git
   cd Basic_portfolio
   ```

2. **Open `index.html`** in any web browser:
   - On Windows: Double click `index.html` or run `start index.html`
   - Using VS Code: Right-click and choose **Open with Live Server**
